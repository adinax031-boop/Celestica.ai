# Celestica AI
## The science of reliable intelligence

Three working exhibition laboratories ask how we can check what an AI learns, proposes or generates. Across each lab, the workflow is **propose → measure → verify → accept, correct or reject**. The experiments share evidence fields and verification contracts. They use separate models and research systems.

**Download [index.html](index.html) and open it in a browser.** The self-contained HTML runs without network access. Train the digit network first, inject a spacecraft failure next and use the recorded KC challenge as a short third demonstration.

| Laboratory | What runs | Measured result |
|---|---|---|
| Memory | Browser neural training, replay, gradient interference, risk prediction, gated updates | Five-seed earlier-digit accuracy was 0.0% sequential, 86.5% replay and 72.4% risk-gated |
| Axiom | Rotatable orbit, discrete solar/battery optimization and independent state-of-charge verification | 148/160 feasible designs versus 88/160 for a fixed pair. All 160 decisions matched exhaustive verification on the same catalog |
| KC | Recorded specialist comparison, offline logic simulation and optional isolated live local inference | Historical original 12/30, KC adapter 6/30 and retrospective route 16/30. The route used 42 calls versus 30 |

The integrated Memory × Axiom investigation trained a small binary feasibility predictor across simulated nominal and degraded conditions. Earlier-environment accuracy was 71.7% sequential, 81.8% replay and 77.7% risk-gated. The independent physics verifier remains the decision authority.
